# Agente local — sin cuenta, sin llaves, sin nube

Corre en tu máquina con **Ollama**. No toca Gandia, ni Handeia, ni ninguna API.

```bash
ollama serve && ollama pull llama3.2
node agente.mjs
```

## Qué demuestra

1. **Tres capacidades de origen distinto** se comportan como un solo sistema:
   una función tuya, un proyecto HTTP, y herramientas importadas.
2. **La autoridad detiene lo peligroso** — y lo ves en pantalla.
3. **El modelo lo pones tú.** El SDK no trae ninguno.

Si ves el bloqueo funcionando, entendiste el producto.
